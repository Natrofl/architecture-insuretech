# Анализ Текущей Архитектуры

## Основные Проблемы и Риски

### 1. Синхронные Запросы к API Страховых Компаний
- **Проблема**: Текущая синхронная модель запросов создаёт задержки и блокировки при взаимодействии с API страховых компаний.
- **Риск**: Рост числа страховых компаний увеличит количество таких запросов, что может привести к более частым отказам и уменьшению производительности.

### 2. Зависимость от Единого Сервиса ins-product-aggregator
- **Проблема**: Высокая нагрузка и потенциальные сбои в ins-product-aggregator приводят к затруднениям в работе core-app и ins-comp-settlement.
- **Риск**: Увеличение количества данных и запросов ухудшит производительность и может стать узким местом в инфраструктуре.
